## Community Packages

### User Interaction

<Accordion title="vk-io-question">
  **Repository:** [fakemancat/vk-io-question](https://github.com/fakemancat/vk-io-question)

  Simple promise-based prompt for asking users questions and waiting for responses.

  ```javascript
  import { QuestionManager } from 'vk-io-question';

  const questionManager = new QuestionManager();

  const answer = await questionManager.ask({
      userId: context.senderId,
      question: 'What is your name?'
  });
  ```
</Accordion>

<Accordion title="vk-io-pages">
  **Repository:** [MrZillaGold/vk-io-pages](https://github.com/MrZillaGold/vk-io-pages)

  Dynamic pagination module for creating paginated menus and lists with keyboard navigation.

  Perfect for:
  - Displaying long lists across multiple pages
  - Creating navigable catalogs
  - Building interactive menus with navigation buttons
</Accordion>

### Bot Frameworks

<Accordion title="henta">
  **Repository:** [u14-team/henta](https://github.com/u14-team/henta)

  A simple and lightweight VK bot engine built on top of VK-IO.

  Features:
  - Easy-to-use command system
  - Built-in middleware support
  - Simplified bot development workflow
</Accordion>

### Storage & State Management

<Accordion title="vk-io-redis-storage">
  **Repository:** [xtcry/vk-io-redis-storage](https://github.com/xtcry/vk-io-redis-storage)

  Redis storage adapter for [@vk-io/session](https://github.com/negezor/vk-io/tree/master/packages/session).

  ```javascript
  import { SessionManager } from '@vk-io/session';
  import { RedisStorage } from 'vk-io-redis-storage';

  const sessionManager = new SessionManager({
      storage: new RedisStorage({
          host: 'localhost',
          port: 6379
      })
  });
  ```

  Perfect for production environments where you need persistent session storage across bot restarts.
</Accordion>

### Framework Integrations

<Accordion title="nestjs-vk">
  **Repository:** [xtcry/nestjs-vk](https://github.com/xtcry/nestjs-vk)

  NestJS module for integrating VK-IO with [NestJS](https://github.com/nestjs/nest) framework.

  Features:
  - Dependency injection for VK-IO instances
  - Decorator-based update handlers
  - Seamless integration with NestJS ecosystem

  ```typescript
  import { VkModule } from 'nestjs-vk';

  @Module({
      imports: [
          VkModule.forRoot({
              token: process.env.VK_TOKEN
          })
      ]
  })
  export class AppModule {}
  ```
</Accordion>

## Contributing Your Module

Built something useful for the VK-IO community? We'd love to feature it here!

<Steps>
  <Step title="Ensure quality">
    Make sure your package:
    - Has clear documentation
    - Includes TypeScript typings
    - Is published on npm
    - Has a public GitHub repository
  </Step>
  
  <Step title="Submit a request">
    [Create a new issue](https://github.com/negezor/vk-io/issues/new) on the VK-IO repository with:
    - Package name and npm link
    - GitHub repository link
    - Brief description of functionality
    - Example usage code
  </Step>
  
  <Step title="Get listed">
    Once reviewed, your package will be added to this page
  </Step>
</Steps>

## Package Guidelines

When building packages for VK-IO, consider these best practices:

<CardGroup cols={2}>
  <Card title="TypeScript Support" icon="code">
    Include TypeScript definitions for better developer experience
  </Card>
  
  <Card title="Documentation" icon="book">
    Provide clear README with installation and usage examples
  </Card>
  
  <Card title="Peer Dependencies" icon="link">
    List vk-io as a peer dependency to avoid version conflicts
  </Card>
  
  <Card title="Testing" icon="vial">
    Include tests to ensure reliability and prevent regressions
  </Card>
</CardGroup>

<Note>
  Package naming convention: Use `vk-io-*` prefix for community packages to make them easily discoverable on npm.
</Note>
