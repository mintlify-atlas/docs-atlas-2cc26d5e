# Welcome to VK-IO

VK-IO is a powerful [Node.js](https://nodejs.org) module that allows you to easily interact with the VK API. Built with TypeScript and designed for modern development, VK-IO provides a predictable abstraction over the VK API with complete feature coverage.

## Key Features

### Intuitive API Design

VK-IO provides a clean, predictable interface that maps directly to VK API methods:

```javascript
// Simple and intuitive
vk.api.users.get({ user_ids: [1] });
vk.api.wall.post({ message: 'Hello, VK!' });
vk.api.messages.send({ peer_id: 123, message: 'Hi!' });
```

### Powerful Bot Development

Build sophisticated bots with middleware support, keyboard builders, and rich message contexts:

```javascript
import { VK, Keyboard } from 'vk-io';

const vk = new VK({ token: process.env.TOKEN });

vk.updates.on('message_new', async (context) => {
  await context.send('Hello! 👋', {
    keyboard: Keyboard.builder()
      .textButton({ label: 'Click me' })
      .inline()
  });
});

vk.updates.start();
```

## What You Can Build

VK-IO is perfect for building:

- **Chat Bots** - Interactive conversational bots with keyboards and commands
- **Community Managers** - Automated posting and community interaction tools
- **Analytics Tools** - Data collection and analysis applications
- **Integration Services** - Connect VK with other platforms and services
- **Custom Clients** - Build your own VK client applications

## Ecosystem Packages

VK-IO comes with a rich ecosystem of official packages:

- **[@vk-io/hear](https://github.com/negezor/vk-io/tree/master/packages/hear)** - Simple command and pattern matching
- **[@vk-io/session](https://github.com/negezor/vk-io/tree/master/packages/session)** - Session management for user state
- **[@vk-io/scenes](https://github.com/negezor/vk-io/tree/master/packages/scenes)** - Middleware-based conversation flows
- **[@vk-io/streaming](https://github.com/negezor/vk-io/tree/master/packages/streaming)** - Real-time data streaming
- **[@vk-io/authorization](https://github.com/negezor/vk-io/tree/master/packages/authorization)** - User authorization flows
