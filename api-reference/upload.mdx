The `Upload` class provides methods for uploading various types of files to VK including photos, videos, documents, audio files, and more.

## Constructor

```typescript
import { Upload } from 'vk-io';

const upload = new Upload({
  api: vk.api
});
```

<Note>
Typically, you don't need to instantiate Upload directly. Use `vk.upload` from the VK instance instead.
</Note>

### Parameters

<ParamField path="options" type="IUploadOptions" required>
  Configuration options for the Upload instance.
  
  <Expandable title="IUploadOptions Properties">
    <ParamField path="api" type="API" required>
      API instance for making VK API calls.
    </ParamField>
    
    <ParamField path="agent" type="Agent">
      Custom HTTPS agent for upload requests.
    </ParamField>
    
    <ParamField path="uploadTimeout" type="number" default={20000}>
      Timeout in milliseconds for upload operations.
    </ParamField>
  </Expandable>
</ParamField>

## Photo Upload Methods

### photoAlbum()

Uploads photos to a VK album.

```typescript

  album_id: 123,
  source: {
    value: 'path/to/photo.jpg'
  }
});
```

<ParamField path="params" type="IUploadParams" required>
  <Expandable title="Parameters">
    <ParamField path="source" type="UploadSource" required>

    </ParamField>

      Album ID to upload to.
    </ParamField>
    
    <ParamField path="group_id" type="number">
      Community ID (if uploading to community album).
    </ParamField>

</ParamField>

## Upload Sources

All upload methods accept various source types:

### File Path

```typescript
await vk.upload.messagePhoto({
  peer_id: 123,
  source: {
    value: '/path/to/photo.jpg'
  }
});
```

### URL

```typescript
await vk.upload.messagePhoto({
  peer_id: 123,
  source: {
    value: 'https://example.com/photo.jpg'
  }
});
```

### Buffer

```typescript
import fs from 'fs';

const buffer = fs.readFileSync('photo.jpg');

await vk.upload.messagePhoto({
  peer_id: 123,
  source: {
    value: buffer
  }
});
```

### Stream

```typescript
import fs from 'fs';

const stream = fs.createReadStream('photo.jpg');

await vk.upload.messagePhoto({
  peer_id: 123,
  source: {
    value: stream
  }
});
```

### Multiple Files

```typescript
// Upload up to 5 photos to album
const photos = await vk.upload.photoAlbum({
  album_id: 123,
  source: {
    values: [
      { value: 'photo1.jpg' },
      { value: 'photo2.jpg' },
      { value: 'photo3.jpg' }
    ]
  }
});
```

### Custom Metadata

```typescript
await vk.upload.messagePhoto({
  peer_id: 123,
  source: {
    value: buffer,
    filename: 'custom-name.jpg',
    contentType: 'image/jpeg',
    contentLength: buffer.length
  }
});
```

## Examples

### Upload and Send Photo

```typescript
import { VK } from 'vk-io';

const vk = new VK({ token: process.env.VK_TOKEN });

  peer_id: 123,
  source: {
    value: 'path/to/photo.jpg'
  }
});

await vk.api.messages.send({
  peer_id: 123,
  message: 'Check out this photo!',
  attachment: photo,
  random_id: 0
});
```

### Error Handling

```typescript
import { VK, UploadError } from 'vk-io';

const vk = new VK({ token: process.env.VK_TOKEN });

try {
  const photo = await vk.upload.messagePhoto({
    peer_id: 123,
    source: {
      value: 'nonexistent.jpg'
    }
  });
} catch (error) {
  if (error instanceof UploadError) {
    console.error(`Upload error: ${error.message}`);
    console.error(`Error code: ${error.code}`);
  }
}
```

## Best Practices

<Tip>
**File Format Support**:
- **Photos**: JPG, PNG, GIF (max 50MB)
- **Videos**: MP4, AVI, MOV (max 6GB for regular users)
- **Audio**: MP3, OGG (for voice messages)
- **Documents**: Any format (max 200MB)
</Tip>

<Warning>
**Upload Timeouts**: Large files may take time to upload. Increase `uploadTimeout` if needed:
```typescript
const vk = new VK({
  token: process.env.VK_TOKEN,
  uploadTimeout: 60000 // 60 seconds
});
```
</Warning>

<Note>
**Attachment Strings**: Convert attachments to strings for API calls:
```typescript
const photo = await vk.upload.messagePhoto({ /* ... */ });

// Use toString() or template literal
await vk.api.messages.send({
  attachment: photo.toString(), // or `${photo}`
  // ...
});
```
</Note>
